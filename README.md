# Hawreh Khaledian — Front-End Portfolio

A modern dark-themed personal portfolio website built to showcase front-end development skills, projects, and contact information.

## ✨ Features

- Responsive layout for desktop, tablet, and mobile
- Mobile hamburger navigation
- Projects showcase
- Skills section
- About-me section
- Contact section
- Social media links
- Dark developer-style UI
- Responsive project cards
- CSS animations and hover effects

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Design
- Remix Icon

## 📱 Responsive Navigation

The mobile navigation is controlled with JavaScript. On smaller screens, the desktop navigation is replaced by a hamburger button that opens and closes the menu.
